বাজার দর (BazarDor)

বাজার দর (BazarDor) is a web application that helps users check and compare the latest prices of daily essential commodities in Bangladesh. It provides an easy way to explore product prices, monitor price changes, and view market-wise price information through a user-friendly Bengali interface.

🚀 Technologies Used

Next.js – React framework for building the web application

React.js – Component-based user interface

JavaScript – Application logic and functionality

Tailwind CSS – Responsive styling and UI design

MongoDB – Database for user and application data

Better Auth – User authentication and account management

HeroUI – UI components for forms and interactive elements

React Toastify – Toast notifications and user feedback

Vercel – Application deployment and hosting

✨ Key Features

📊 Daily Market Prices – Explore the latest prices of essential commodities in Bangladesh.

📈 Price Change Tracking – Monitor price increases and decreases compared with previous records.

🔍 Category-Based Browsing – Browse products by categories such as rice and other daily essentials.

🏪 Market-Wise Price Comparison – View minimum and maximum prices across different markets and divisions.

🔐 User Authentication – Sign up, sign in, and access protected features with Better Auth.
